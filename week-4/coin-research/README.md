# 코인 시장 리서치

2026년 10월 기준 암호화폐 시장 리서치를 대시보드로 만든 것.
Playwright로 수집한 리서치 결과 + 공개 API 실시간 시세를 한 화면에서 본다.

**배포 주소:** https://coin-research-delta.vercel.app

## 실행

```powershell
npm start                  # http://localhost:6007
```

`npx serve`를 쓰므로 설치할 의존성이 없다.

> `file://`로 직접 열면 안 된다. CORS 요청이 `Origin: null`로 나가서 API가 거절한다.
> 반드시 HTTP로 띄워야 한다.

로컬에서는 `/api/upbit`가 없지만, 업비트를 직접 부르는 경로로 자동으로 넘어가므로 그대로 동작한다
(이유는 아래 "2. 업비트가 vercel.app 출처를 막는 문제" 참고).
서버리스 함수까지 로컬에서 그대로 돌려보려면 `npx vercel dev`를 쓴다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 + 데이터 수집 + 계산. React 18 + Tailwind CDN 단일 파일 |
| `api/upbit.js` | 업비트 시세 프록시 (의존성 없는 서버리스 함수) |
| `vercel.json` | `/api/*`만 함수로, 나머지는 `index.html`로 |
| `package.json` | 로컬 실행 스크립트만. 런타임 의존성 없음 |

## 화면

해시 라우팅으로 5개 탭을 둔다.

| 경로 | 내용 |
| --- | --- |
| `#/` | 핵심 판단, 지표 6종, 52주 범위 내 위치, 이동평균 배열 |
| `#/market` | 시가총액 상위 시세, 김치 프리미엄, ETF 자금 흐름 |

| `#/risk` | 손실로 이어지는 행동 6가지, 확인할 변곡점 일정 |

## 데이터 — 실시간과 스냅숏을 나눠 둔 이유

공개 API가 있는 건 실시간으로 부르고, 없는 건 리서치 당시 수집값을 `SNAPSHOT` 상수에 박아 뒀다.
섞어 쓰되 **출처와 성격을 화면에 표시**한다.

| 항목 | 출처 | 갱신 |
| --- | --- | --- |
| 시세·시가총액·도미넌스·사상최고 대비 낙폭 | CoinGecko `/coins/markets`, `/global` | 90초 |
| 원화 체결가·52주 범위 | Upbit `/v1/ticker` (프록시 경유) | 90초 |
| 원/달러 환율 | open.er-api.com | 90초 |
| 공포·탐욕 지수 | alternative.me `/fng/` | 90초 |
| 금리·고용·이동평균·고래 포지션·ETF·알트시즌 | 기사·CoinMarketCap에서 수집 | 고정 (수집 시각 표기) |

금리나 고래 포지션은 무료 공개 API가 없어서 실시간으로 만들 수 없었다.
그래서 **고정값이라는 걸 숨기지 않고** 헤더에 "스냅숏 기준 2026-10-05 17:35 KST"를 띄운다.

### 김치 프리미엄은 직접 계산한다

프리미엄을 주는 API를 쓰지 않고 세 값을 받아 그 자리에서 계산한다.

```
프리미엄 = 업비트 원화 체결가 ÷ (CoinGecko 달러가 × 환율) − 1
```

이렇게 하면 업비트에 상장된 종목이면 뭐든 프리미엄이 나오고,
환율이 어디서 왔는지도 화면에 같이 띄울 수 있다.

## 구현하면서 해결한 문제

**1. 업비트에 없는 심볼 하나가 요청 전체를 죽이는 문제**
`/v1/ticker?markets=KRW-BNB` 처럼 상장되지 않은 마켓이 목록에 섞이면 응답이 통째로 실패한다.
BNB·HYPE 같은 종목이 여기 걸렸다.
→ `/v1/market/all`로 **KRW 마켓 목록을 먼저 받아** 거기 있는 심볼만 골라 요청한다.
목록은 자주 바뀌지 않으므로 **localStorage에 하루** 캐시해서 매 로드마다 받지 않는다.

**2. 업비트가 `vercel.app` 출처를 막는 문제 — 배포하고서야 드러났다**
로컬에서는 멀쩡하던 김치 프리미엄이 배포본에서만 통째로 비었다.
브라우저에는 `Failed to fetch`만 뜨고 상태 코드조차 안 보여서 원인 찾는 데 가장 오래 걸렸다.

처음엔 레이트리밋인 줄 알고 재시도·간격 조정을 넣었는데 해결되지 않았다. 세 가지를 비교해 보고서야 원인이 잡혔다.

| 어디서 불렀나 | 결과 |
| --- | --- |
| `curl` (Origin 헤더 없음) | 200 |
| 브라우저 · `http://localhost:6007` | 200 |
| 브라우저 · `https://example.com` | 200 |
| 브라우저 · `https://coin-research-delta.vercel.app` | **실패** |

같은 URL·같은 시각·같은 IP인데 **출처만 다르면 막힌다.** 업비트가 무료 호스팅 도메인을 CORS에서 거르는 것으로 보인다.
→ `api/upbit.js` 서버리스 함수를 두고 **서버가 대신 받아 같은 오리진으로 돌려준다.**
브라우저와 업비트 사이에 출처 문제가 아예 생기지 않는다.

열린 프록시가 되지 않도록 **쓰는 두 경로(`market/all`, `ticker`)만 허용**하고,
마켓 코드도 정규식으로 거른 뒤 URL을 서버에서 다시 조립한다.
응답에는 `s-maxage`를 걸어 시세 10초 / 마켓 목록 1시간 동안 **CDN이 재사용**한다 —
방문자가 늘어도 업비트로 가는 요청 수는 그대로다.

로컬 정적 서버에는 `/api/upbit`가 없으므로, 실패하면 업비트를 직접 부르는 쪽으로 넘어간다.
localhost 출처는 업비트가 허용하니 **배포본과 로컬이 각각 다른 경로로 똑같이 동작**한다.

**3. API 하나가 죽으면 화면 전체가 비는 문제**
`Promise.all`로 묶으면 5개 중 하나만 실패해도 전부 날아간다.
→ `Promise.allSettled`로 바꾸고, **실패한 것만 골라** 상단에 노란 배너로 알린다.
나머지는 받은 값으로 그리고, 전부 실패하면 `SNAPSHOT.fallback` 값으로 떨어진다.
빈 화면 대신 "조금 오래된 값"을 보여주는 쪽을 택했다. 2번을 찾는 동안 이 배너가 어디가 죽었는지 바로 알려줬다.

**4. 색만으로 등락을 표시하면 못 읽는 사람이 있다**
적록색맹에서 초록과 빨강은 사실상 구분되지 않는다(색차 ΔE ≈ 1).
→ 모든 등락에 **부호(+/−)와 화살표(▲/▼)를 같이** 넣었다. 색은 보조 수단으로만 쓴다.
`pctParts()` 한 곳에서 처리하므로 표든 카드든 표시가 어긋나지 않는다.

**5. "고점 대비"가 두 가지 의미로 쓰이던 문제**
시세표의 낙폭은 **사상 최고가** 기준(CoinGecko)이고, 사이클 바의 낙폭은 **52주 고점** 기준(업비트)이다.
같은 라벨을 쓰니 ADA가 −91%인지 −30%인지 헷갈렸다.
→ 각각 "사상 최고 대비", "52주 고점 대비"로 **라벨을 분리**했다.

**6. 청산 레벨 사다리에서 라벨이 현재가 핀에 가리는 문제**
가운데에 "현재 레인지" 글자를 뒀는데, 현재가가 대체로 구간 한가운데라 핀이 글자를 뚫고 지나갔다.
→ 가운데 라벨을 없앴다. 양쪽 끝 라벨과 축 눈금만으로 의미가 전달된다.

**7. 탭이 숨겨져 있어도 90초마다 API를 때리는 문제**
CoinGecko 무료 티어는 분당 호출 수 제한이 있다. 탭을 여러 개 열어두면 금방 걸린다.
→ `document.hidden`이면 갱신을 건너뛰고, **탭으로 돌아올 때 `visibilitychange`로 한 번만** 다시 받는다.

## 배포

```powershell
npx vercel link --yes --project coin-research
npx vercel deploy --prod
```

환경변수가 필요 없다. API 키를 쓰는 곳이 한 군데도 없다
(CoinGecko·Upbit·alternative.me·er-api 전부 무인증 공개 엔드포인트).

### ⚠️ PC 이름이 한글이면 Vercel CLI가 죽는다

이 PC는 컴퓨터 이름이 `행정실장`이라 `vercel` 명령이 전부 이 오류로 멈췄다.

```
TypeError: Cannot convert argument to a ByteString because the character
at index 0 has a value of 54665 which is greater than 255.
```

`54665`는 `행`(U+D589)이다. Vercel CLI가 `os.hostname()`을 HTTP 헤더에 싣는데,
HTTP 헤더는 Latin-1만 담을 수 있어서 한글에서 터진다.
`COMPUTERNAME` 환경변수를 바꿔도 소용없다 — `os.hostname()`은 OS API에서 직접 읽는다.

→ 그 명령을 돌리는 동안만 `os.hostname()`을 ASCII로 바꿔 끼운다.
시스템 설정은 건드리지 않는다.

```js
// ascii-hostname.cjs
const os = require('os');
os.hostname = () => 'localhost';
```

```powershell
$env:NODE_OPTIONS = "--require C:\경로\ascii-hostname.cjs"
npx vercel deploy --prod
```

근본적으로 고치려면 Windows 설정에서 PC 이름을 영문으로 바꾸면 된다(재부팅 필요).

## 참고

- 투자 권유가 아니다. 공개 데이터를 정리한 리서치 노트다.
- 청산가와 고래 포지션은 **제3자가 온체인 데이터를 추정한 값**이라 실제와 다를 수 있다.
- CoinGecko 무료 티어는 호출 제한이 있어서, 많이 보면 429가 날 수 있다.
  그때는 노란 배너가 뜨고 스냅숏 값으로 표시된다.
- `.vercel/`과 `.env.local`(Vercel이 만든 OIDC 토큰)은 `.gitignore`로 제외돼 있다.
