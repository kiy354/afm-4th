# _비공개 — 이 워크스페이스의 비공개 파일 목록
> 원본 조직에는 실제 협력업체·인플루언서·계정 식별자가 담긴 메모리가 있었다 (supplier-db, admin, influencer, design 실물, growth 실물, md-sales, health, me …).
> **이 클래스 간소판에는 그 파일들을 하나도 가져오지 않았다.** 디자인·그로스 메모리는 데모로 새로 썼다.

## 현재 비공개 파일: 없음
- 실제 원본·브라우저 로그·계정 식별자는 배포본에서 제외했다.
- 현재 배포 폴더는 화면 공유·녹화·스크린샷 가능.

## 지키는 것
- 실제 키·토큰·계정 ID·전화번호·이메일을 이 폴더 어디에도 넣지 않는다. (`_secrets/` 폴더도 만들지 않는다)
- 실습 중 실제 브랜드 데이터를 넣게 되면 이 파일에 경로를 적고 헤더에 `🔒 비공개`를 단다.
