- 브리핑 순서는 본부 고정(경영→그로스→크리에이티브→대표 직속). 순서가 흔들리면 대표님이 못 찾는다.

- 팀 메모리 `## 다음 할 일`에 날짜 붙은 줄이 곧 "그 팀장이 내일 할 것". 오늘·내일 날짜만 띄우고 지난 건 "(지남)".
- 숫자는 KPI 표에서만. 브리핑 본문에 숫자를 풀어 쓰면 판정처럼 읽힌다.
