| HEX | 자리 (대표컷에서) |
|---|---|
| `#F7F5F0` | **배경 (기본)** — 웜 오프화이트 |
| `#2F3A36` | **잉크 — 제목·본문·haru 텍스트** — 세이지 잉크 |

⛔ **쓰면 ❌ 위반**: 채도 있는 색 전부(핑크·코랄·골드·네이비) · 순검정 `#000000` · 순백 `#FFFFFF` 배경. 기능색(에러 빨강·네이버 초록)도 대표컷 X.
→ 대표컷 배경은 **`#F7F5F0` 또는 `#E8ECE6` 둘 중 하나.** "따뜻한 톤"은 색이 아니라 여백으로 낸다.

## 2. 타이포
| 자리 | 폰트 | 대표컷 값 |
|---|---|---|
| 영문 라벨·짧은 영문 | **Cormorant Garamond** (Google Fonts CDN · 안 뜨면 Georgia 폴백) | Title Case · weight 400 |
| 한글 전부 · 영문 긴 문장 | **Pretendard** (CDN) | weight 400 (강조는 500까지) |
| haru 브랜드 표기 | 다른 폰트와 같은 면이면 **로고 아니라 텍스트** `haru` (Cormorant Garamond) | 로고 SVG는 단독 면에서만 |

**금지 3** — 이탤릭 · 올캡(`text-transform: uppercase`) · 위 표 외 폰트.
**크기로 위계 주지 않는다** — 대표컷(1080px 캔버스)은 **제목 40~48 · 부제 22~24 · 메타 18** 안에서, 제목과 부제의 차이는 **2단계 이내**. 위계는 크기보다 **폰트(영문 세리프↔한글 산세리프)·정렬·여백**으로.

## 3. 대표컷 규격 (블로그 템플릿 §4 "대표컷(01)")
- 캔버스 **1080 × 1440** (세로) · **글자는 위쪽 1080 × 1080 안에** (네이버 썸네일이 정사각으로 자른다)
- 잉크 `#2F3A36` · 배경 `#F7F5F0`(기본) 또는 `#E8ECE6`
- 좌측 정렬 · 좌우 inset은 간격 스케일에서 (**64 또는 96**) · 세로 간격도 스케일 값만: `8 · 16 · 24 · 32 · 48 · 64 · 96`
- 요소 4개 이하: 영문 라벨(예 `Haru Journal`) · 제목 · 부제 · 하단 메타(`haru` 텍스트 + 날짜). 느낌표·최상급 X
- 아래 1080~1440 구간은 비워 두거나 아주 옅은 구분선 1개 (`#DED9CF`) — 사진이 들어갈 자리
- 모서리 각짐(`border-radius: 0`) · 그림자·그라데이션 X · 비대칭(왼쪽 축) = 하루 결
