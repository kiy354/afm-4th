# 하루 디자인 토큰 — 1층 화이트리스트
> 이 값들은 **하루 확정 SSoT에서 추출**한 것.
> ⚠️ 데모 데이터 — 클래스 교보재용 가상 브랜드. 여기 없는 값은 쓰지 않는다. 요약(`design-system.md`)과 다르면 이 파일이 맞다.
갱신: 260920

## 1. 색 (5)
| 토큰 | HEX | 자리 |
|---|---|---|
| `--w` | `#F7F5F0` | 배경 기본 (웜 오프화이트) |
| `--ink` | `#2F3A36` | 잉크 — 제목·본문·브랜드 텍스트 |
| `--sub` | `#8C918B` | 서브 · 캡션 · 날짜 |
| `--line` | `#DED9CF` | 밑줄 · 구분선 |
| `--g5` | `#E8ECE6` | 배경 대안 (페일 세이지) |

⛔ 채도색 전부 · `#000000` · `#FFFFFF` 배경 · 기능색(에러·네이버 초록)은 대표컷 X.

## 2. 간격 스케일
`8 · 16 · 24 · 32 · 48 · 64 · 96` — 이 값만. 좌우 inset은 64 또는 96.

## 3. 타이포
| 자리 | 폰트 | 규칙 |
|---|---|---|
| 영문 라벨·브랜드 텍스트 | Cormorant Garamond (Google Fonts) · 폴백 Georgia | Title Case · 400 |
| 한글·긴 영문 | Pretendard (CDN) · 폴백 Apple SD Gothic Neo | 400 (강조 500) |

**금지 3** — 이탤릭 · 올캡 · 표 외 폰트.
크기: 제목 40~48 · 부제 22~24 · 메타 18. 제목↔부제 2단계 이내.

## 4. 컴포넌트 (대표컷)
- 캔버스 1080×1440 · 글자는 위쪽 1080×1080
- 요소 4개 이하 · 좌측 정렬 · 각진 모서리 · 그림자·그라데이션 X

### 🔒 불변 (어디서나 = 하루다움)
- 배경은 `--w` / `--g5` 둘 중 하나
- 잉크 하나, 서브 하나. 색으로 위계 X
- 로고 **중앙** → 하루는 **좌측**
- `MENU / CART(0)` 워딩 → 하루 워딩
- 여백이 곧 브랜드 — 요소를 더하지 말고 뺀다
