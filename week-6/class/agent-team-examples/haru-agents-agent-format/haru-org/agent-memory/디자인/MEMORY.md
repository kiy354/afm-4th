## 노하우 (누적)
- 브랜드 5색뿐. 채도 있는 색은 대표컷에 ❌. 배경은 `white`(①정보글) / `grey #E8ECE6`(②매거진) 둘 중 자동, 고르느라 묻지 않는다.
- 영문 Cormorant Garamond는 Google Fonts CDN. 안 뜨면 Georgia 폴백. 한글은 Pretendard CDN.
- 금지 3: 이탤릭·올캡·다른 폰트. 라벨은 `Haru Journal` Title Case로.
- playwright는 `file://`이 막혀 있다 → 프로젝트 루트에서 `python3 -m http.server 8765` 띄우고 `http://127.0.0.1:8765/...` 로 연다. 스크린샷 filename은 프로젝트 안 절대경로여야 저장된다.
- Pretendard CDN이 안 뜨면 Apple SD Gothic Neo로 떨어진다 — 자간이 살짝 넓어 보이지만 허용.
- 제목 20자 넘으면 `title long`(40px). 그래도 2줄 넘으면 제목을 줄이고 부제로 내린다. 요소 추가는 답이 아니다.
- 산출물 파일명은 컨텐츠 폴더 규격을 따른다: `_발행_N편_<주제>/01_대표컷.html/.png`.
