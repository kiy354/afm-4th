# 하루 브랜드 아이덴티티

> 포지셔닝, 비주얼 아이덴티티, 타겟 페르소나 종합.
> ⚠️ **데모 데이터** — 클래스 교보재용 가상 브랜드. 인물·이력·수치 전부 창작.
> 마지막 업데이트: 2026-09-20

---

## 1. 포지셔닝

### 브랜드 포지션
- **카테고리**: 욕실 웰니스 (타월 + 워시바)
- **핵심 약속**: 매일의 씻는 시간을 "하루를 닫는 의식"으로
- **차별점**: 소재 하나에 집중한 타월 라인 + 향으로 하루를 정리하는 워시바 + 절제된 언어

### 포지셔닝 맵
```
        고가격
          |
  수입 럭셔리 ─┤─ 호텔 어메니티 브랜드
          |
  HARU  ──┤── 디자인 리빙 편집숍 PB
          |
  국산 중가 ─┤── 대형마트 PB
          |
        저가격

  감성/라이프스타일 ←──────────→ 기능/가성비
```

### 경쟁 우위
1. **소재 집중**: 라인당 소재 하나. 설명이 짧다
2. **제품 철학**: "써보고 이해한 것만 판다"
3. **브랜드 언어**: 과장 없는 문장, 여백
4. **의식 프레이밍**: "비누"가 아니라 "하루를 닫는 도구"

## 2. 비주얼 아이덴티티

### 컬러 팔레트
- 값은 `agent-memory/디자인/design-system.md` §1 만 인용 (여기서 추측 금지)
- 웜 오프화이트 바탕 + 세이지 잉크. 채도 높은 색 없음

### 비주얼 톤
- **키워드**: 절제, 여백, 뉘앙스, 비트렌드
- **피해야 할 것**: 과장된 자연주의, 트렌디한 그래픽, 색상 과다, 핑크/코랄 톤

### 포토 스타일
- 자연광, 정면보다 비스듬히, 제품은 화면의 1/3 이하

## 3. 타겟 페르소나

### 페르소나 A: 감성 유입층 (25-34세)
- **유입 경로**: 감성/라이프스타일 콘텐츠
- **반응 포인트**: 브랜드 무드, 향
- **구매 패턴**: 소량 (1-2개), 첫 구매 → 재구매 잠재
- **감정 트리거**: "나만 보는 물건을 좋은 것으로"

### 페르소나 B: 실용+프리미엄 핵심층 (35-44세)
- **유입 경로**: 제품 스펙, 비교 콘텐츠
- **반응 포인트**: 품질, 소재, 상세 스펙
- **구매 패턴**: 타월 핵심 구매군
- **감정 트리거**: "매일 쓰는 것이 매일을 바꾼다"

### 페르소나 C: 선물/세트 구매층 (45-54세)
- **유입 경로**: 시즌 이벤트, 선물 키워드
- **반응 포인트**: 패키징, 세트 구성
- **구매 패턴**: 높은 객단가, 묶음
- **감정 트리거**: "받는 사람 욕실에 오래 남는 선물"

### 공통 감정 구매 트리거
1. 하루 끝의 보상
2. 나만 보는 물건을 좋은 것으로
3. 매일 쓰는 것이 매일을 바꾼다
4. 좋은 걸 써보면 이전으로 못 돌아간다
