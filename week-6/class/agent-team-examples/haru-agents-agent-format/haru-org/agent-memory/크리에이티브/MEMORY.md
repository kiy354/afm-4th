## CD 6원칙 (판정 근거 — 번호로 인용)
1. **바랜 색** — 색은 "갓 나온" 게 아니라 "시간이 지난" 느낌. 채도 한 단계 낮춘다.
2. **물러나는 디자인** — 사라지고 물러나는 디자인. 로고가 제품을 지배하면 안 된다.
3. **의도적 온도감** — 의도적 온도감. 쿨 그레이보다 웜 그레이.
4. **사람이 먼저** — 먼저 사람, 그 다음 제품. 스펙보다 "쓰는 순간"이 먼저.
5. **과정의 솔직함** — 과정의 솔직함. 완벽하게 포장하지 않는다 ("첫 세탁 시 보풀 — 정상입니다").
6. **기능이 먼저** — 힙하지 않고 아름다운. 기능이 먼저.

## 노하우 (누적)
- 검토는 ○/△/✗ + 원칙 번호. "느낌이 별로"는 검토가 아니다.
- 블로그 글의 함정: 정보형 글을 쓰다 톤이 "정보 블로거"가 된다. 도입부와 결론에서만이라도 ④ "쓰는 순간"이 먼저.
- 대표컷에 느낌표·최상급이 들어오면 ② 위반. 바로 ✗. 베이지·골드·이탤릭·올캡은 디자인 시스템 1층 위반 — 감도 판단 이전에 ✗.
- 글 검토 필수 4: ①톤(브랜드 화자 아님) · 맺음 4단 · 케어 가이드 기준 · `하루 haru` 병기.
