## 1. 두 계정의 보이스 DNA

### @haru.official — "조용한 안내자"
- **화자**: 브랜드 → "당신". 2인칭 부드러운 권유
- **문장**: 짧고 완결. 줄바꿈으로 여백
- **감정**: 차분·안정. 감탄사 없음
- **마무리**: 질문형이 절반

### @haru.note — "작업실 기록자"
- **화자**: "나". 만드는 사람의 1인칭
- **문장**: 짧은 메모체. 마침표 생략 잦음
- **감정**: 고민·시행착오를 그대로
- **마무리**: 열린 채로 끝남

## 4. 문장 구조 특징

> 하루에서 제일 조용한 시간일 때가 있어요.

> 얇긴 한데 마르는 게 확실히 빠르다.
>
> 이걸로 갈지 고민.

## 7. 교차 분석: 광고 카피 vs 오가닉

| 비교 항목 | 광고 카피 | 오가닉 (@official) | 오가닉 (@note) |
|----------|----------|-------------------|----------------|
| 톤 | 장면+소재 설명 | 장면+여백 | 과정+미결 |
| 길이 | 2~3줄 | 3~5줄 | 2~4줄 |
| CTA | 소프트 ("한 번 써보세요") | 없음 (질문) | 없음 |

### 리퍼포즈 기회
1. **official 장면 → 광고 훅**: "물기를 닦는 시간이…" → 릴스 오프닝
2. **note 과정 → 릴스**: "샘플 세 번째" → 제작 과정 숏폼
3. **official 질문 → 광고 CTA**: "오늘은 어땠나요" → 소프트 CTA
