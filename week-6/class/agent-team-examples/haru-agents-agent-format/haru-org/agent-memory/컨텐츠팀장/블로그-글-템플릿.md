### 사진
- **위치**: 소제목 바로 아래(홀수 번 소제목 위주) + 맺음 직전 1장. 순서 = 소제목 → 사진 → 본문

- **캡션**: 비교컷에만 (제품·중량 명시. 예 `좌측 - 하루 Cloud Cotton 타월 그레이 250g / 우측- 일반 40수 세면타올`) · 나머지 캡션 없음
- **대표컷(01)**: 디자인팀장 몫 (`/디자인 대문 <제목>`). 틀 = `agent-memory/디자인/블로그-대문-템플릿.html` (1080×1440 · 글자는 위쪽 1080×1080 안에 · 영문 Cormorant Garamond / 한글 Pretendard · 잉크 #2F3A36). 산출물 `01_대표컷.png`

기기 예시는 **사람들이 상상하기 쉽게 많이 쓰는 것들로** — 제품·코스 이름을 본문에 박는다 (LG 타월 코스 · 삼성 40도 기본값 · 통돌이 냉수 · 퍼실 딥클린 실내건조).
상위 글이 "삶으세요"라고 해도 따라 쓰지 않는다. 충돌하면 원고 머리에 `⚠️ 상위글 통설과 다름: …` 한 줄.

## 7. 🚨 브랜드명 표기 — 한글 「하루」만 쓰면 검색이 안 잡힌다

「하루」는 일반명사라 「하루 수건」「하루서울」로 검색하면 브랜드가 아니라 일상 글에 전부 매몰됨. **「하루 haru」 영문 병기만 작동.**
→ 본문·맺음·태그에 브랜드를 쓸 때 반드시 `하루 haru` 형태로.

## 8. 발행 절차 (이 워크스페이스 기준)

1. 폴더 만들기 `0_지금/<트랙>/_발행_N편_주제/` → `_복붙용.txt` 작성 → 사진 자리 `〔사진 02_xxx.jpg〕` + 어떤 컷인지 한 줄
2. `/디자인 대문 <제목>` → 같은 폴더에 `01_대표컷.png`
3. 원고 셀프 체크 — 글자수 1,000+ · 소제목 문어체·번호 · 굵게 1곳 · 맺음 4단 · 태그 5~9 · `하루 haru` · §6 케어 기준 · `/토씨검증 <원고 경로>`
4. (선택) `/크리에이티브 검토` — 하루다운가
5. **대표님 컨펌 → 발행 클릭은 대표님.** 발행 도구(`3_채우기.mjs`)는 워크스페이스에 없음 → 원고를 네이버 에디터에 복붙
6. 발행 링크 받으면 작업로그에 URL + 발행일 기록 → 다음 날 `/컨텐츠팀장 조회수`
