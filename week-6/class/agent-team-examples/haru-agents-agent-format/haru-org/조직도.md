## 보고 흐름 (오늘 실습)
```
비서실 (아침)  →  리서치팀장 4·5편 후보 2  →  디자인 대문(4편 대표컷)  →  컨텐츠팀장 4편 원고  →  (크리에이티브 검토)  →  각자 저장  →  비서실 (다시)
```
- 모든 팀장은 일 끝나면 `agent-memory/<팀>/MEMORY.md` + `0_지금/<작업>/_작업로그.md` 머리를 갱신한다 (`_shared/메모리-저장-공통.md`).
- 비서실은 그 파일들을 읽는다. **저장 안 한 일은 브리핑에 안 뜬다.**

## 조직 바꾸기 (자기 조직 꾸리기)
1. 팀장 추가: `.claude/agents/<에이전트>.md` (frontmatter `name`·`description`·`tools` + 역할·읽는 파일·모드·저장·룰) + `haru-org/agent-memory/<이름>/MEMORY.md` (고정 구조) + 이 표에 한 줄
2. 팀장 이름·말투 바꾸기: 해당 에이전트 파일의 역할·말투 문장 수정
3. 본부 순서 바꾸기: `.claude/agents/비서실.md`의 보고 순서 + 이 파일
4. **브랜드를 내 것으로**: `/조직꾸리기` — 이 kit를 틀로 내 컴퓨터 자료 + 인터뷰로 `내조직/`을 만든다 (README §5)
