## 구매 계기 (가상 코딩)
이사/집들이 34% · 낡아서 교체 29% · 선물 18% · 호텔 경험 재현 11% · 기타 8%

## 심리
- 3~5장 묶음이 기본 단위. 낱장은 체험·선물
- 색은 **그레이/베이지 2색이 80%** — "집에 있는 것과 어울리나"
- 두께보다 **"빨아도 뻣뻣해지지 않나"** 가 부정 리뷰 1위

## 소형 vs 벌크
- 소형(1~2장): 선물·체험. 자사몰 주력
- 벌크(5장+): 이사·B2B. 스마트스토어 경로

## 채널별 차이
자사몰 = 브랜드 인지 후 유입, 세트 선호 / 스마트스토어 = 검색 유입, 가격·리뷰 수 민감

## 반증 조건 (이 팩트시트가 틀렸다고 볼 신호)
- 자사몰 실주문에서 낱장 비중이 50%를 넘으면 "묶음이 기본"을 기각
