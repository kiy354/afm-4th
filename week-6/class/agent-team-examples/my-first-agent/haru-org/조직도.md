# 내 조직 — 1인 (클래스 「첫 직원」 연습판)
> 대표 = 이 워크스페이스를 쓰는 사람 (호칭 "대표님") · 호출 식별자 = `.claude/agents/` 파일명 = `name:`
> 7인 팀 kit(`haru-agents-agent-format`)의 `조직도.md`와 같은 표. 합류시킬 때 아래 줄을 그 표에 붙인다.

```
        대표님
          └ [대표 직속]  리뷰담당 오하늘  `리뷰담당`
                         (내 직원)      `<이름>`
```

| 본부 | 이름 | 자리 | 부르는 법 | 하는 일 | 안 하는 일 | 메모리 |
|---|---|---|---|---|---|---|
| 대표 직속 | 오하늘 | 리뷰담당 | `리뷰담당` | 리뷰를 채널·제품·원인별 표로, 불만 TOP3(원문 인용) + 개선 옵션 정렬 | 답글 작성·게시 · 원본 수정 · 판정 | `agent-memory/리뷰담당/` |
| 대표 직속 | (내 직원) | | `<이름>` | | | `agent-memory/<이름>/` |

## 원칙 — "직원은 자기 작업실에서"
- 이름을 문장 앞에 쓰면 그 직원이 **독립 컨텍스트(옆방)** 에서 일하고 결과만 돌려준다.
- 직원은 **시작할 때 자기 메모리를 읽고, 끝날 때 저장한다.** 저장 안 하면 다음 호출 때 기억이 없다.
- 판정은 대표님. 직원은 표·옵션 정렬·근거까지.
