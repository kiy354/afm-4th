# 작업로그 공통 룰 — 전 팀장 필수
갱신: 260715 18:00 (제정)

## 1. 위치 — 한 군데로 고정
- 멈춘 일·이어하기 상태 = **무조건 `haru-org/0_지금/<작업명>_YYMMDD/` 폴더의 `_작업로그*.md`**
- agent-memory(팀 메모리) = **노하우·체크리스트·정의만.** 작업 상태를 팀 메모리에 남기면 반칙 — 대표님이 못 찾는다.

## 2. 스캔용 머리 — 파일 맨 위 고정 블록
현황판이 이 머리만 읽는다. 형식 엄수:

```
---
작업: 수건세트 런칭이벤트
담당: 조정우(/shop)
협조: 나미란(/ops)
상태: ⏸️멈춤
멈춘 지점: 세트를 컬러별 SKU로 쪼갤지 미결
다음 할 일: 대표님 결정 받으면 배포 AI 지시서 작성
갱신: 260715 18:00
---
```

- `협조:` 없으면 줄 생략. **몫까지 표기**: `류혜진(/리서치팀장) — 4·5편 주제 2개` (현황판이 협조자 블록에도 회색으로 비춰줌)
- 선택 필드 3개 (해당할 때만):
  - `연결: <작업명>` — 다른 작업과 맞물릴 때 (양쪽 머리에 서로 적기)
  - `검토: 배유나(/크리에이티브)` — 본부장급이 봐줘야 하는 작업. 현황판이 그 본부장 밑에 "검토 요청"으로 모아준다
  - `풀리면: <장면 한 줄>` — **대표님 손이 필요한 작업(⏳대기)은 필수.** 이게 풀리면 어떤 장면이 열리는지. 공포("안 하면 망함") ✗, 열리는 장면 ○. 아침 브리핑이 이 줄을 읽어 대표님께 보여준다
- 🚨 **⏳대기(대표님 손) 전용 2줄** — 상태를 대표님 대기로 바꿀 때 반드시 같이 채운다 (아침 브리핑이 대표님께 보여주는 줄):
  - `대표님: <가장 작은 물리 행동 한 문장> (예상 ○분)` — 팀장용 문장 금지. "터미널에 ○○라고 치기 / A·B 중 택1 / 파일 던져주기"처럼 **바로 실행 가능한 동사**로
  - `왜 지금: <마감·막힌 사람>` — 진짜 급한 것만. 안 급하면 줄 생략 (전부 급하다 = 아무것도 안 급하다)
- `상태:` 4종만 — `🔴진행중` | `⏸️멈춤` | `⏳대기`(대표님 컨펌·외부 응답 등) | `✅완료`
- `갱신:` **반드시 시간까지** (`YYMMDD HH:MM`)
- **일 멈출 때마다 머리만 최신화.** 본문은 노드 사슬 보존(압축=문장 줄이기, 노드 삭제 X)

## 3. 한 작업의 범위
- **"~하면 끝"이 한 문장으로 말해지는 덩어리** = 작업 1 = 폴더 1 = 담당 1명
- 30분 단발 → 폴더 X, `haru-org/workspace/0-ing/haru-할일.md` 한 줄
- 몇 달짜리 목표(예: 전환율 올리기) → 작업이 아니라 사슬. 사슬 밑에서 작업이 떨어져 나온다.

## 4. 두 팀장이 겹칠 때
- **오너는 무조건 1명** + `협조:` 표기. 로그는 오너가 관리, 협조자 일도 오너 로그에 순차 기록.
- 몫이 크게 갈리면(각자 따로 굴러가면) **작업을 2개로 쪼갠다.**
- 현황판에는 오너 밑에 한 번만 뜬다 (+협조 배지).
