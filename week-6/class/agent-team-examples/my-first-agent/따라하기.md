# 따라하기 — 빈 폴더에서 이 구조 만들기

> 20분 · VS Code + Claude Code 확장(설치돼 있음) · 터미널 없음
> 끝나면 `my-first-agent/`와 같은 구조에 **내 직원 1명**이 들어 있다. 파일은 전부 Claude에게 시켜 만든다 — 붙여넣기만 하면 된다.

## 만드는 것
```
내폴더/
├── .claude/agents/<이름>.md             ① 직원 — 역할·절차·금지 (한 장)
├── haru-org/
│   ├── memory/haru-팩트시트.md           ② 기준 — 제품명·가격·용어
│   ├── agent-memory/_shared/             ③ 공통 룰 3장 (복사)
│   ├── agent-memory/<이름>/MEMORY.md     ④ 직원의 기억
│   ├── _fixtures/<일감 파일>             ⑤ 일감 — 직원이 읽을 자료
│   ├── 조직도.md                         ⑥ 누가 있나
│   └── 0_지금/                           ⑦ 작업로그·산출물 — 직원이 만든다
├── 직원-템플릿.md · 채용공고.md          (복사)
```
`.claude/agents/` = 누가 무엇을 어떻게 · `haru-org/` = 무엇을 아는가·어디까지 했나. 7인 팀 kit도 이 구조 그대로다.
폴더 이름 `haru-org`는 kit와 맞추기 위한 것 — 내 브랜드여도 처음엔 그대로 둔다 (직원 파일 안의 경로가 전부 이 이름).

## 0. 폴더 열기 (2분)
1. 바탕화면에 새 폴더 — 이름은 영문 (예 `my-first-agent`)
2. VS Code → **File → Open Folder** → 그 폴더 → "작성자를 신뢰합니까?" → **신뢰**
3. 왼쪽 **Claude 아이콘** → 채팅창이 열리면 준비 끝

## 1. 뼈대 폴더 (1분)
채팅창에 붙여넣기:
```
빈 폴더를 만들어줘: .claude/agents, haru-org/memory, haru-org/agent-memory/_shared, haru-org/_fixtures, haru-org/0_지금
```
"실행할까요?" → **예**. 탐색기에 `.claude`와 `haru-org`가 보이면 됨.

## 2. 복사 5장 (2분) — 내용을 바꾸지 않는 파일
`my-first-agent/`에서 VS Code 탐색기로 끌어다 놓는다.

| 원본 | → 내 폴더 |
|---|---|
| `haru-org/agent-memory/_shared/` 3장 (보고룰·작업로그·메모리 저장) | `haru-org/agent-memory/_shared/` |
| `직원-템플릿.md` · `채용공고.md` | 맨 위(루트) |

공통 룰 3장은 팀 kit와 **같은 파일** — 나중에 합류할 때 충돌이 없다.

## 3. 기준 파일 (3분) — `haru-org/memory/haru-팩트시트.md`
직원이 인용할 사실(제품명·가격·용어) 한 장. 연습이면 `my-first-agent/haru-org/memory/haru-팩트시트.md`를 복사. 내 브랜드면 붙여넣기:
```
haru-org/memory/haru-팩트시트.md 를 만들어줘. 표 3개 — ① 제품 (카테고리 | 제품 | 가격 | 비고) ② 배송 (무료배송 기준 · 배송비) ③ 용어 (쓰면 안 되는 말 → 쓰는 말). 모르는 칸은 "미확인". 내용:
(내 제품·가격·용어를 여기에)
```

## 4. 일감 (2분) — `haru-org/_fixtures/<파일>`
직원이 읽을 자료 1개. CSV·xlsx·md·txt 아무거나. **이름·연락처·계정은 지우고** 넣는다.
- 연습: `my-first-agent/haru-org/_fixtures/reviews-수건.csv` 복사
- 내 것: 리뷰 내보내기 · 문의 모음 · 주문 표 · 회의록 …

## 5. 직원 파일 + 메모리 (5분) — `.claude/agents/<이름>.md` · `agent-memory/<이름>/MEMORY.md`
`채용공고.md` 아래쪽 빈칸을 채워 **통째로** 붙여넣는다 (형식은 `직원-템플릿.md`가 잡아 준다). "파일 만들까요?" → **예** (두 번 — 직원 파일 · 메모리 파일).
확인:
```
<이름> 직원 파일 보여줘
```
7칸(이름 · 언제 부르나 · 도구 · 읽는 파일 · 모드/절차/출력 · 저장 · 룰)이 다 있고 `{{`가 없으면 통과. 빠진 칸은 한 칸씩: `<이름> 직원 파일 룰에 "원본 수정 금지" 추가해줘`
- 이름 규칙: 파일명 = `name:` = 부르는 말. 한글(`리뷰담당`) 또는 영문 소문자·하이픈. 띄어쓰기 X
- `.claude/agents/` 안에는 직원 파일만 — 템플릿을 거기 두면 직원으로 읽힌다

## 6. 조직도 (1분) — `haru-org/조직도.md`
```
haru-org/조직도.md 를 만들어줘. 표 한 줄 — 본부 | 이름 | 자리 | 부르는 법 | 하는 일 | 안 하는 일 | 메모리. 내 직원 <이름>을 대표 직속으로.
```

## 7. 첫 업무 → 저장 확인 (3분)
```
<이름> <기본 호출어>
```
직원의 여는 말로 시작하는 보고가 오면 위임 성공. 끝나면 탐색기에서 두 곳:
- `haru-org/0_지금/<작업>_YYMMDD/` — `_작업로그.md` + 결과 파일이 **새로 생겼는가** ⑦
- `haru-org/agent-memory/<이름>/MEMORY.md` — `## 배움`에 오늘 한 줄 · `## 다음 할 일`에 날짜 붙은 줄

둘 다 있으면 구조 완성. 없으면: `저장 안 됐어. 직원 파일 A-4대로 저장하고 🗂 저장 줄까지 보고해줘`

## 8. 남았나 (1분)
```
/clear
<이름> <기본 호출어>
```
같은 여는 말 · 같은 표가 나오면 — 직원은 채팅이 아니라 **파일**이다. 끝.

## 체크리스트
- [ ] `.claude/agents/<이름>.md` — 7칸 · `{{` 없음
- [ ] `haru-org/agent-memory/_shared/` — 3장
- [ ] `haru-org/agent-memory/<이름>/MEMORY.md` — 고정 구조
- [ ] `haru-org/memory/haru-팩트시트.md`
- [ ] `haru-org/_fixtures/<일감>` — 개인정보 없음
- [ ] `haru-org/조직도.md` — 내 직원 한 줄
- [ ] `haru-org/0_지금/<작업>_YYMMDD/_작업로그.md` — 첫 업무 뒤 생김
- [ ] `/clear` 후에도 같은 결과

## 막히면
| 증상 | 처방 |
|---|---|
| `.claude` 폴더가 안 보임 | 탐색기 빈 곳 우클릭 → New Folder → `.claude` (점 포함) |
| 이름을 불러도 직원 여는 말이 없음 | `<이름> 에이전트로 …` 라고 부르기 · `description:`에 요청 예 추가 |
| 파일을 못 만들겠다고 함 | 폴더를 "신뢰"했는지 · Open Folder로 **내 폴더**를 열었는지 |
| 저장을 안 함 | `tools:`에 `Write, Edit` 있는지 · 직원 파일에 "A-4. 저장 (필수)" 있는지 |
| 그 외 | `뭐가 문제인지 네가 진단해줘` |
