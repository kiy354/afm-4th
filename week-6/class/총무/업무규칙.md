# 업무규칙.md — 총무 업무 규칙

## 공통

1. 문서는 반드시 `서식/` 의 해당 서식을 채워서 만든다. 서식에 없는 항목을 임의로 추가하지 않는다.
2. 산출물은 `완료문서/` 에 저장한다. 파일명: `YYYYMMDD-문서종류-상대방.md` (예: `20260922-세금계산서요청-달빛교육.md`)
3. 모르는 정보는 지어내지 않는다. 비어 있으면 "확인 필요"로 남기고 보고한다.
4. 금액은 원화, 천 단위 쉼표로 쓴다 (예: 3,300,000원).

## 세금계산서 규칙

1. 발행에 필요한 거래처 필수 정보 4가지: **상호 · 대표자 · 사업자등록번호 · 이메일**.
   하나라도 없으면 발행요청서를 만들지 말고, 누락 항목을 정리해 담당자에게 보고한다.
2. 사업자등록번호는 `000-00-00000` 형식인지 확인한다.
3. 부가세: 세액 = 공급가액의 10%.
   - 요청 금액이 "VAT 포함(총액)"이면: 공급가액 = 총액 ÷ 1.1 (원 미만 버림), 세액 = 총액 − 공급가액.
   - "VAT 별도"면: 공급가액 = 요청 금액, 세액 = 공급가액 × 10%.
4. 검산: 공급가액 + 세액 = 합계. 안 맞으면 발행하지 않는다.
5. 발행 기한: 요청 접수일로부터 2영업일.

## 서류 검토 규칙

1. 검토는 5개 체크리스트로 한다:
   ① 금액 계산 일치 (모든 숫자를 직접 더해 검산)
   ② 날짜·기간 논리 (지급일이 완료일보다 빠르지 않은지 등)
   ③ 필수 조항 유무 (대금지급 · 검수 · 해지 · 손해배상 · 비밀유지)
   ④ 우리 회사에 불리한 독소 조항 (무제한 배상, 일방 해지, 과도한 권리 귀속 등)
   ⑤ 오탈자·표기 오류
2. 지적마다 위험도 **상/중/하** 를 붙이고, 수정 문안을 제안한다.
3. 보고서 끝에 다음 문구를 반드시 넣는다: "본 검토는 내부 참고용이며 법률 자문이 아닙니다. 중요 계약은 변호사 검토를 권장합니다."
